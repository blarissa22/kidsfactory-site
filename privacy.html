Política de Privacidade do KidsFactory

Atualizada em 28 de outubro de 2026.

O KidsFactory usa os Serviços de API do YouTube. Ao usar o KidsFactory, você concorda com os Termos de Serviço do YouTube. A Política de Privacidade do Google também se aplica.

Quem usa o app

O KidsFactory é usado apenas pelo dono dos canais Lia & Amigos e Lia & Friends, no próprio computador. Ele não coleta dados de espectadores, não tem cadastro de usuários e não é oferecido a terceiros.

Quais dados o app acessa

  • Dados dos canais do próprio dono, pela YouTube Data API: lista de vídeos, títulos, descrições e status de envio.
  • Métricas agregadas dos próprios canais, pela YouTube Analytics API (visualizações, tempo assistido, inscritos).
  • Dados públicos de vídeos e canais infantis obtidos por busca (títulos, contagem de visualizações, datas).

O app não acessa dados pessoais de espectadores, comentários de usuários ou informações de crianças.

Como os dados são usados

Os dados servem só para enviar e agendar os vídeos dos próprios canais e para decidir quais temas produzir em seguida. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Armazenamento e exclusão

  • Os dados ficam num banco local no computador do dono, sem servidor externo.
  • Dados obtidos da API do YouTube são apagados automaticamente após 30 dias.
  • O token de acesso fica num arquivo local protegido e pode ser revogado a qualquer momento em permissões da Conta do Google. Ao revogar, o app perde o acesso imediatamente, e os dados locais podem ser apagados pelo dono a qualquer momento.

Cookies

O KidsFactory não usa cookies nem rastreadores. Esta página também não usa.
